# x402 price index

Listed per-call prices from public x402 marketplaces, collected by [Tanod](https://tanod.dev/data/). Snapshot in this repository: **2026-10-27**; newer daily files are on the [download page](https://tanod.dev/data/).

## Data

- [`data/x402-category-prices.json`](data/x402-category-prices.json): category offers, hosts and price quartiles.
- [`data/x402-category-prices-history.csv`](data/x402-category-prices-history.csv): dated category history.
- [`data/x402-bazaar-stats.json`](data/x402-bazaar-stats.json): Bazaar listings, networks, schemes, prices and metadata quality.
- [`data/x402-bazaar-stats-history.csv`](data/x402-bazaar-stats-history.csv): dated Bazaar history.
- [`data/x402-prices.md`](data/x402-prices.md): separate hand-checked comparisons with their own snapshot dates.

These are listed prices, not proof of sales or prices actually paid. Categories use keyword matching and can include unlike services; duplicated, stale or mispriced listings affect results. See each file's method and snapshot date. Historical Tanod price columns describe their recorded date; [live API prices](https://tanod.dev/openapi.json) are authoritative for new calls.

Canonical download page: **https://tanod.dev/data/**. Related analysis: [Bazaar overview](https://tanod.dev/learn/state-of-x402-bazaar.html) and [facilitator support](https://tanod.dev/learn/x402-facilitator-support.html).
